# File Organizer — Python Automation Tool

A Python-based file organization tool that automates file management by sorting files into categorized folders based on their file extensions.

## Overview

The File Organizer is a Python automation project designed to make file management easier by reducing the need to organize files manually.

## Features

- Automatically organizes files based on file extensions
- Categorizes files into separate folders
- Reduces repetitive manual file management
- Uses Python's file-handling and operating system capabilities

## Python Concepts Used

- **File Handling:** Working with files and directories
- **OS Module:** Interacting with the file system
- **Functions:** Organizing code into reusable functions
- **Conditional Statements:** Applying rules to categorize files
- **Loops:** Processing multiple files automatically

## Technologies Used

- Python
- Python `os` module
- File System Automation

## How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run the Python script:

```bash
python main.py
```

Replace `main.py` with your actual Python filename if it is different.
